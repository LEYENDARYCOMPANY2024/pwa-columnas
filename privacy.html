Política de privacidad

Aplicación: Varilla para columnas
Última actualización: 11 de noviembre de 2026

Información que utiliza la aplicación

La aplicación funciona sin crear una cuenta. Para realizar los cálculos, utiliza los valores que ingresas, como dimensiones de columnas, cantidades, medidas de varilla, separación, desperdicio y, si lo proporcionas, precio por kilogramo. También puede guardar esos valores y tu preferencia de tema en el almacenamiento local de tu navegador o dispositivo, para conservarlos entre visitas.

Estos datos permanecen en tu dispositivo y la aplicación no los envía al desarrollador. Los campos están destinados a datos de cálculo; no ingreses información personal o sensible.

Compartir y exportar

Si eliges usar las funciones de compartir o exportar, la aplicación prepara los resultados para compartirlos mediante las opciones de tu dispositivo o para descargarlos como archivos. La información solo se comparte con el destino que tú selecciones.

Almacenamiento y eliminación

Los valores guardados pueden borrarse desde la configuración del navegador, eliminando los datos del sitio. También puedes usar «Restablecer valores» para reemplazar los valores del cálculo guardados por los valores predeterminados.

Conexiones y terceros

La aplicación no incorpora publicidad, analítica ni servicios propios que recopilen datos de uso. El sitio se aloja en GitHub Pages; GitHub puede procesar información técnica de las solicitudes para prestar y proteger el servicio, de acuerdo con su Declaración de privacidad.

Menores de edad

La aplicación no está dirigida a recopilar información personal de menores.

Cambios y contacto

Esta política puede actualizarse si cambia la aplicación. Las modificaciones se publicarán en esta página. Para consultas sobre privacidad, puedes contactar al responsable mediante el repositorio del proyecto.
